# AlgoLab Roadmap

Plan for roughly 3–5 hours a week, which is 1–2 lessons. Tick a box when its tests pass.

Every lesson follows the same loop:
1. Read `lessons/lessonNN_*.md` and try the examples yourself.
2. Fill in the `# TODO`s in `exercises/lessonNN_*.py`.
3. Run the tests with `pytest tests/test_lessonNN.py -v` until they are all green.
4. Save your progress with Git (you'll learn how in Lesson 4).

## Part 1: Python refresher
- [x] **01 Basics:** running Python, variables, types, if/else, functions
- [x] **02 Lists & loops:** lists, `for`, `while`, `range`, building up results
- [x] **03 Strings, dicts & sets:** the tools behind half of all interview problems
- [ ] **04 Git, GitHub & going live:** push this repo and deploy the AlgoLab home page
- [ ] **05 Classes & objects:** the building block of every data structure
- [ ] **06 Big-O & recursion:** how interviewers measure code, and functions that call themselves

## Part 2: Data structures
Each lesson has four parts: build the structure from scratch in `algolab/`, write its tests, add a live visualizer page in `pages/`, and solve 3–5 classic interview problems with it.
- [ ] **07 Dynamic array:** how a Python `list` works under the hood
- [ ] **08 Linked list:** reverse a list, detect a cycle, merge two sorted lists
- [ ] **09 Stack:** valid parentheses, min stack
- [ ] **10 Queue:** queue from two stacks, recent-calls counter
- [ ] **11 Hash map:** two-sum, group anagrams, first unique character
- [ ] **12 Binary search tree:** insert, search, traversals, validate a BST
- [ ] **13 Heap / priority queue:** top-K elements, merge K sorted lists
- [ ] **14 Graph:** BFS, DFS, number of islands
- [ ] **15 Trie:** autocomplete, word search
